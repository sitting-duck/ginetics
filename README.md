# Ginetics Juice

Website for Ginetics Juice.

## Preview

```bash
python3 -m http.server 5173
```

Then visit [http://localhost:5173](http://localhost:5173).

## Pages

- `index.html` — home
- `menu.html` — juices, ingredients, boosts
- `learn.html` — color, detox, cleanse
- `about.html` — our story
- `faq.html` — FAQ
- `order.html` — orders and inquiries
- `disclaimer.html` — health and shipping notes
- `privacy.html` — privacy policy
